## Build CasparCG

Extract the complete CEF distribution and configure with:

    cmake -S src -B build-cef154-h264 -G Ninja \
      -DCMAKE_BUILD_TYPE=Release \
      -DENABLE_HTML=ON -DENABLE_AVX2=ON -DENABLE_VULKAN=OFF \
      -DUSE_STATIC_BOOST=OFF -DUSE_SYSTEM_CEF=OFF \
      -DCEF_LOCAL_ROOT=/absolute/path/to/extracted/distribution \
      -DCMAKE_INSTALL_PREFIX=/absolute/path/to/isolated/stage
    cmake --build build-cef154-h264 --parallel 4
    cmake --install build-cef154-h264

The wrapper is built from the selected distribution; matching binaries
and resources are installed. Set LD_LIBRARY_PATH to the staged lib directory.
Concurrent tests need separate configuration, cache, logs and AMCP port,
with hardware consumers already in use excluded.

An empty CEF_LOCAL_ROOT with USE_SYSTEM_CEF=OFF retains the pinned Spotify
download fallback, which lacks this custom build's H.264 support.
USE_SYSTEM_CEF=ON retains the existing system-package behavior.

## Tested workload, 2026-10-05

Ubuntu 24.04 headless/X11, NVIDIA GTX 1070, AJA Corvid44, 1080p50:

- H.264 MP4/MSE and WebRTC capabilities advertised.
- H.264 WebRTC and HLS playback worked.
- Pixi 8.18.1 WebGL2 live video, graphics and two VP9-alpha WebM overlays
  rendered smoothly for a user-reported run longer than 30 minutes.
- Final 30-second capture: 1500 incoming frames, uploads and render ticks;
  zero FIFO underflows, repeats or overflow losses.
- User reported successful restart/reload, clip-to-AJA source switching
  and next-day startup, without observed CEF errors or restarts.

Smoothness also depends on separately maintained STREAM/player changes:
opt-in STREAM queues 12/64, receiver hint 200 ms, application FIFO 12/cap24,
timestamp pacing, texImage2D, deterministic VideoFrame ownership and one
render loop. Preserve Pixi's browser-specific WebM alpha detection.

Other frame rates/platforms, production-duration testing and actual player
integration remain open. The cleaned CasparCG build compiled successfully
after temporary HTML diagnostics were removed; runtime smoke test pending.
